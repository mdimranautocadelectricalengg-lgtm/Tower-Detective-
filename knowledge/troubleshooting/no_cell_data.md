# No Cellular Data

If the application displays no cellular information:

1. Check that a SIM is active.
2. Check that Location is enabled.
3. Check Android application permissions.
4. Check whether the device supports the requested information.
5. Check whether the device is connected to a cellular network.
6. Check Android logs for SecurityException.
7. Test on another supported Android device.

Do not assume that no data means there is no tower nearby.
